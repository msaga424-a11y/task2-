Task 2 - لغة الجافا سكريبت ودورها في منصات الويب الحديثة
للطالبة رنا مجاهد محمد مجاهد - ID: 2500101

المقدمة ▼

تعتبر لغة JavaScript واحدة من أهم لغات البرمجة في عصرنا الحالي، وهي واحدة من الأعمدة الثلاثة للويب بجانب HTML و CSS. تم إنشاؤها عام 1995 على يد المبرمج بريندان إيتش في شركة Netscape في 10 أيام فقط.

في البداية كانت تُستخدم لإضافة حركات بسيطة للصفحات مثل التحقق من النماذج، لكن اليوم أصبحت نظام بيئي ضخم يتم استخدامه لبناء منصات كاملة مثل فيسبوك ويوتيوب وجوجل درايف وجيت هاب نفسه.

ما هي الجافا سكريبت وكيف تعمل؟ ▼

الجافا سكريبت هي لغة برمجة عالية المستوى ومفسرة وديناميكية، كل متصفح حديث يحتوي على محرك JavaScript Engine مثل V8 في جوجل كروم يقوم بتنفيذ الكود فوراً بدون الحاجة لترجمة مسبقة.

HTML يبني هيكل الصفحة - CSS يضيف الألوان - JavaScript يضيف السلوك والتفاعل

تعمل اللغة بنظام الأحداث Events، وتستطيع تغيير محتوى الصفحة بدون إعادة تحميلها باستخدام AJAX و Fetch API.

أهم المميزات مع أمثلة ▼

1. التلاعب بعناصر الصفحة DOM:

document.getElementById('title').innerText = "مرحبا جيت هاب";

2. أطر العمل: React.js (فيسبوك) و Angular (جوجل) و Vue.js

3. Node.js: منذ 2009 سمح للجافا سكريبت أن تعمل على السيرفر، ويمكن بناء منصة كاملة مثل نتفليكس بها.

4. الربط مع GitHub API:

fetch('https://api.github.com/users').then(r=>r.json()).then(d=>console.log(d));

5. الذكاء الاصطناعي: الاتصال بـ Gemini API لإضافة ميزات ذكية.

دورها في التعليم والتخزين السحابي ▼

في منصات مثل Google Classroom و Google Drive و GitHub، تقوم الجافا سكريبت بـ: التعاون اللحظي، السحب والإفلات، الاختبارات التفاعلية، والعمل بدون إنترنت باستخدام Service Workers.

الخاتمة ▼

تطورت الجافا سكريبت من مشروع صغير مدته 10 أيام إلى العمود الفقري للإنترنت الحديث. تعلمها يفتح مجالات عمل كثيرة: مطور واجهات أمامية بـ React، ومطور موبايل بـ React Native، ومطور ويب بـ Node.js.
